About

This site provides an interactive map and dataset for mining titles in Tunisia. It is a static site powered by Leaflet and GeoJSON; it is easy to extend to fetch live data from a backend or a GIS service.

Included sample data

A small sample GeoJSON is included at assets/data/mining_titles.geojson. Replace it with your real data or upload via the UI.
